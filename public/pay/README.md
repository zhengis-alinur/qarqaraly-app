# QR-код для оплаты

Положите сюда статический QR Halyk файлом `halyk-qr.png` (или укажите другое имя
в `PAYMENT_QR`). Пока файла нет, блок оплаты на сайте не показывается, а
`/dashboard/pay` сообщает, что оплата не настроена.

Сумму плательщик вводит вручную — показывается она из `PAYMENT_AMOUNT`.
Подтверждение оплаты на сайт не приходит: поступление сверяется по выписке,
а объект публикует модератор в `/admin`.
